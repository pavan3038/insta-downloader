# Insta Downloader

Instagram Reel / video downloader website (Hindi + English, light + dark). Frontend + Node.js backend, **zero dependencies** (Node 18+).

## चलाने का तरीका
```bash
cp .env.example .env      # फिर .env में अपनी API key/token भरें
npm start                 # http://localhost:3000
npm test                  # backend tests (mock APIs के साथ)
```

## API Integration (कोई पेड API अपने-आप नहीं जोड़ी गई)
बिना API के साइट चलती है, पर डाउनलोड पर साफ़ Error दिखता है ("API कॉन्फ़िगर नहीं है") और होमपेज पर चेतावनी आती है।

1. **आधिकारिक Instagram API (मुफ़्त)** – `IG_ACCESS_TOKEN`. यह सिर्फ़ *उसी अकाउंट* के वीडियो देती है जिसका टोकन है (Instagram का आधिकारिक API दूसरों के Reels की फ़ाइल नहीं देता)।
2. **Custom API (वैकल्पिक)** – `CUSTOM_API_URL`, `CUSTOM_API_HEADERS`, `CUSTOM_VIDEO_PATH` आदि। दूसरों के Public Reels के लिए आप कोई ऐसी सेवा चुनें जिसकी शर्तें आपके उपयोग की अनुमति देती हों। Response का JSON path `.env` में बताया जाता है; कोई कोड बदलना ज़रूरी नहीं।

`PROVIDER=auto` में पहले आधिकारिक API, फिर Custom API आज़माई जाती है। Keys सिर्फ़ सर्वर के environment में रहती हैं।

## सुरक्षा
- SSRF गार्ड (सिर्फ़ public https मीडिया होस्ट), redirect हर hop पर जाँचा जाता है
- Rate limit, CSP और अन्य security headers, contact form में honeypot
- वीडियो सर्वर पर सेव नहीं होता, सीधे स्ट्रीम होता है (बिना re-encode → original quality); लिंक 15 मिनट में expire

## Deploy
किसी भी Node होस्ट (VPS, Render, Railway…) पर `npm start`। `SITE_URL` सेट करें और proxy के पीछे हों तो `TRUST_PROXY=1`। Contact संदेश `data/messages.jsonl` में जमा होते हैं।

## डाउनलोड कहाँ सेव होता है
- Android: ब्राउज़र का Downloads फ़ोल्डर
- iPhone: Files → Downloads, और "Photos में सेव करें" बटन से Share → Save Video
- PC: ब्राउज़र का डाउनलोड फ़ोल्डर
