How to download

Three simple steps.

  1. Copy the link

    In Instagram open the Reel, tap Share → Copy link.

  2. Paste & check

    Paste it above and press Download. The link is verified and a preview appears.

  3. Save the MP4

    Press Download MP4. Android: Downloads folder. iPhone: Files, or Save to Photos.

    Frequently asked questions

    कौन-से Instagram वीडियो डाउनलोड हो सकते हैं?Which Instagram videos can I download?
    आपके अपने (कनेक्टेड) अकाउंट के वीडियो, और ऐसे Public Reels जिनकी फ़ाइल किसी अधिकृत स्रोत से उपलब्ध हो। कृपया सिर्फ़ वही कंटेंट सेव करें जो आपका हो या जिसकी आपको अनुमति हो।Videos from your own connected account, and public Reels where an authorised source makes the file available. Please save only content you own or have permission for.
    क्या Private अकाउंट के वीडियो डाउनलोड होंगे?Can I download from private accounts?
    नहीं। Private कंटेंट तक कभी एक्सेस नहीं किया जाता।No. Private content is never accessed.
    वीडियो कहाँ सेव होगा?Where is the video saved?
    Android में ब्राउज़र का Downloads फ़ोल्डर। iPhone में Files → Downloads, और "Save to Photos" दबाकर Share → Save Video से गैलरी में। कंप्यूटर पर ब्राउज़र का डाउनलोड फ़ोल्डर।Android: your browser's Downloads folder. iPhone: Files → Downloads, or tap "Save to Photos" and choose Share → Save Video. Computer: the browser's download folder.

    "API कॉन्फ़िगर नहीं है" का क्या मतलब है?What does "API not configured" mean?
    यह वेबसाइट सिर्फ़ अधिकृत API से काम करती है। साइट के एडमिन ने अभी API Key/Token सेट नहीं किया है। (एडमिन: README और .env.example देखें।)This site only works through authorised APIs and the admin has not set the API key/token yet. (Admins: see README and .env.example.)
    मेरा वीडियो "अकाउंट का नहीं है" क्यों दिखा?Why does my video say "not from the connected account"?
    आधिकारिक Instagram API सिर्फ़ उसी अकाउंट के वीडियो देती है जिसका टोकन जुड़ा हो। किसी और अकाउंट का Reel तभी मिलेगा जब एडमिन ने कोई अधिकृत दूसरा स्रोत जोड़ा हो।The official Instagram API only returns videos of the account whose token is connected. Other accounts' Reels work only if the admin has added another authorised source.
